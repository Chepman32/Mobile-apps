# ScanForge — офлайн-сканер PDF для iOS/Android (React Native)

Версия: 1.0

Назначение документа: Полная спецификация (архитектура, UX/UI, флоуы, монетизация, офлайн-ограничения, тестирование) для реализации мобильного офлайн-сканера PDF на React Native без серверной части.

Платформы: iOS 15+ / Android 8.0+

Ключевые требования:
- 100% локальная обработка изображений и текста (OCR) — никаких загрузок в облако.
- Монетизация через In-App Purchases (IAP).
- Производительный UX с авто-детектом границ, автосъёмкой, фильтрами "Документ", "Фото", "Контраст", перспективной коррекцией и локальным OCR (много языков).
- Безопасное локальное хранилище, опционально — локальное шифрование документов и экспорта (пароль на PDF).
- Поддержка тёмной/светлой темы.
- Реализация на React Native (CLI), с фреймворками, доступными офлайн и без обязательной нативной серверной интеграции.

---

## 1) Обзор продукта

ScanForge — мобильное офлайн-приложение для сканирования бумажных документов, чеков, визиток, заметок в многостраничные PDF. Все этапы — камера, детект границ, перспективная коррекция, фильтрация, OCR, сжатие, генерация PDF, просмотр и локальный поиск — происходят на устройстве. Интернет требуется только для покупки/восстановления IAP (техническое требование App Store/Google Play). После покупки функциональность работает без сети.

Ключевые сценарии:
- Быстрое сканирование одним тапом с автодетектом границ и авто-спуском затвора.
- Пакетная съёмка нескольких страниц.
- Точная ручная обрезка и перспективная коррекция.
- Профессиональные фильтры: B/W (Оцу), контраст, фото, серый, “чек”.
- Сжатие PDF (качество/разрешение), настройка DPI.
- Локальный OCR (выбор языков), полнотекстовый офлайн-поиск по всем документам (FTS).
- Защита PDF паролем, локальное шифрование хранилища.
- Маркеры и аннотации (выделение, замазывание персональных данных).
- Теги, папки, избранное, быстрые действия/шаблоны экспорта.
- Экспорт: Файлы (локально), AirDrop (iOS), системный “Поделиться”, принтер (AirPrint/Print). Все — без сервера.

## 4) Бизнес-модель и IAP

**Free (без регистрации, офлайн):**
- Сканирование без водяного знака до 5 страниц в день или до 3 документов в день (конфигурируемо).
- Базовые фильтры (B/W, Фото, Контраст).
- PDF без пароля, качество “среднее”, DPI до 150.
- OCR: 1 язык (например, English) и ограничение на длину OCR-текста/количество страниц с OCR в сутки (например, 5 страниц).
- Нет полнотекстового глобального поиска (поиск только по имени/тегам).
- Нет шифрования хранилища, аннотации урезаны (только выделение).

**Pro — одноразовая покупка:**
- Без ограничений по страницам/документам.
- Все фильтры и пакетные операции.
- PDF-параметры: DPI 72–600, качество JPEG/WEBP, линейризация.
- OCR офлайн: 10+ языков, пакетный OCR, полнотекстовый глобальный поиск (SQLite FTS5).
- Пароль на PDF, локальное шифрование хранилища (ключ в Secure Storage).
- Полный набор аннотаций (маркер, замазывание/редакт, подписи).
- Быстрые действия/шаблоны экспорта.
- Приоритетная локальная очередь (фоновые задачи, возобновление).

Подписка (альтернатива, если потребуется): те же плюсы + косметические “темы Pro”, расширенные языки OCR, быстрые пресеты. Но для офлайн-утилиты лучше единоразовый unlock. В любом случае покупка/восстановление доступны только через системный IAP; после — всё офлайн.

Технически: react-native-iap. Квитанции храним локально, подпись/валидация — системная; периодически “мягкая” проверка при наличии сети (необязательно для работы).

## 5) Нефункциональные требования
**Производительность:**
- Автодетект краёв в предпросмотре камеры ≥ 20 FPS на mid-range.
- Запуск приложения < 1.5 с (cold start), переходы экранов < 300 мс.
- Обработка 1 страницы: коррекция + фильтр + превью < 800 мс (целевой показатель).
**Память:**
- Пиковое потребление < 400–600 МБ на 12-мегапиксельных исходниках.
- Использовать downscale для превью, chunk-обработку, стрим-кодеки.
**Надёжность:**
- Фоновая очередь задач (обработка/OCR/экспорт), авто-резюме после убийства процесса.
- Автосейвы черновиков.
- Защита от потери данных при нехватке памяти/хранилища.
**Доступность:** динамический размер шрифта, контраст, VoiceOver/TalkBack.

## 6) Технологический стек (RN-уровень)
- Камера: react-native-vision-camera + Frame Processors (JSI) для детекта границ/автоспуска.
- Жесты и анимации: react-native-gesture-handler, react-native-reanimated.
- Хранилище:
  - Файлы страниц (JPEG/WEBP) + собранные PDF — в app sandbox.
  - Метаданные и FTS-поиск — react-native-sqlite-storage (SQLite с FTS5).
  - Настройки/флаги — react-native-mmkv.
- OCR (офлайн):
  - iOS: Apple Vision (VNRecognizeTextRequest) офлайн.
  - Android: ML Kit Text Recognition v2 он-девайс.
- Обработка изображений: OpenCV через нативный модуль или JSI.
- PDF: react-native-pdf-lib или нативные API PDFKit/PdfDocument.
- Шифрование: SQLCipher или AES-контейнеры с ключами в Secure Storage.
- IAP: react-native-iap.
- Шеринг/печать: системный share sheet, react-native-print.
- Локализация: react-native-localize + i18n-файлы.

## 7) Доменная модель и схема БД
- **Document**: id, title, createdAt, updatedAt, tags, favorite, pageCount, ocrStatus, hasPassword, encryption.
- **Page**: id, documentId, index, imagePath, thumbPath, cropQuad, filter, dpi, rotation, width/height, processingMeta.
- **OcrChunk**: pageId, lang, text, blocks.
- **Tag**: id, name, color.
- **DocTag**: docId, tagId.
- **ExportPreset**: name, dpi, quality, password?, watermark?

SQLite + FTS5: таблица fts_ocr (docId, pageId, text) для полнотекстового поиска. Индексы по updatedAt, favorite, title.

Файлы: `/Documents/{docId}/pages/{pageIndex}.webp`, `/Documents/{docId}/document.pdf`, `/Thumbs/{docId}.jpg`.

## 28) Риски и меры
- Тяжёлый OCR → выбор языков, batch-OCR.
- Производительность на старых устройствах → downscale, упрощённые фильтры.
- Шифрование PDF на Android → при отсутствии либы — ZIP-пароль.
- IAP офлайн-восстановление → локальный маркер, без сети нельзя восстановить на новом устройстве.
